# CueDeck Review — Deploy readiness

Reviewed: 2026-09-02
Scope: the whole app, packaging, and the cloud free tiers it depends on, with the goal of
shipping a first Windows build that a new user can install and use for free. Findings already
recorded in `REVIEW_2026-09-01.md` and `LATENCY_AND_QUALITY_REVIEW.md` are not repeated.

Verification after the changes: `npm run check` (Prettier, ESLint, strict `tsc`, 296 unit +
147 integration tests), `npm run test:e2e` (15 Playwright specs), `npm run release`, launching
`out/CueDeck-win32-x64/cuedeck.exe`, and loading Whisper Tiny through the packaged
`app.asar` / `app.asar.unpacked` layout with the dev Electron binary in Node mode.

## Final review pass (2026-09-03)

A second review of the whole diff (seven reviewers: three bug hunters, reuse, simplification,
efficiency, altitude) before the first real-call test. Fixed:

| Finding                                                                                                                                                                                              | Fix                                                                                                                                                                                         |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Silence trimming used a 0.004 RMS floor while the capture gate accepts 0.0015, so a softly spoken opening on a quiet loopback feed could be cut before transcription.                                | `SILENCE_SCAN_DEFAULTS` now shares `SILENCE_RMS_THRESHOLD`; regression test in `audio.test.ts`.                                                                                             |
| Every speculative pass re-uploads the clip so far, so a long question with many pauses billed several times its length against Groq Whisper's hourly audio quota.                                    | `MAX_CLOUD_SPECULATIONS_PER_CLIP = 3` (local passes unmetered); tests in `speculation.test.ts`.                                                                                             |
| The secrets vault treated any read failure as an empty vault, so a transient EBUSY/EPERM during `set()`/`remove()` would rewrite `secrets.json` with every other key gone.                           | Missing/corrupt file → empty; I/O errors propagate as `STORAGE_FAILED`.                                                                                                                     |
| Escape was ignored whenever the (now read-only) transcript box had focus, so keyboard cancel silently stopped working.                                                                               | Read-only/disabled fields no longer own Escape; in an editable field Escape now leaves the field (`leave-field`) so the next press cancels.                                                 |
| Transcribing while the same model's explicit download was in flight threw `MODEL_NOT_INSTALLED` instead of joining the download; a warmup for another model killed the downloading worker.           | `transcribeNow` joins an in-flight load of the same model; `ensureModel` waits for a different model's in-flight load before replacing the worker.                                          |
| The user-confirmed remote Ollama origin could be any host, so a bad settings file could send prompts and transcripts to a public address in cleartext.                                               | `isPrivateNetworkHost`: only loopback, RFC 1918 / link-local / ULA literals, `.local`-style or single-label names are ever unlocked; tests in `security.test.ts`; Preferences copy says so. |
| A local STT stage timeout surfaced as a silent `REQUEST_CANCELLED` reset with no banner.                                                                                                             | `LocalWhisperProvider` maps its own timeout to `PROVIDER_TIMEOUT`.                                                                                                                          |
| The corrupt-cache detector matched any "invalid", so a transient "Invalid argument: insufficient memory" would delete a 600 MB model.                                                                | Regex narrowed to parse/protobuf/truncation wording.                                                                                                                                        |
| Opening Preferences at the section it already shows reloaded the page (dropping a half-typed key or a download's progress view).                                                                     | `showPreferencesSection` is a no-op when the hash already matches.                                                                                                                          |
| OpenRouter's `gpt-oss` free models got no reasoning controls (multi-second first token); onboarding still hardcoded Gemini/OpenRouter IDs; Ollama and `prompt.ts` carried private sampling literals. | `openRouterRequestExtras` sends `reasoning: { effort: 'low', exclude: true }`; onboarding presets and Ollama/prompt defaults read `CLOUD_MODELS` / `DEFAULT_*` constants.                   |

| The interviewer follow-up's 160-token cap was shared with gpt-oss's hidden reasoning tokens, so follow-up questions could come back truncated or empty. | `REASONING_TOKEN_HEADROOM` (256) is added to `max_tokens` for reasoning models on Groq, Cerebras and OpenRouter. |
| Cancelling a session did not abort a speculative Groq Whisper request it had already adopted (quota spent for a discarded result); a new session's speculation killed another session's running local inference. | The adopted job is aborted with the session; local in-flight jobs are queued behind regardless of session. |

Noted, not changed (design-level, no user-visible failure today): the three abort-race helpers
and two serial-queue idioms could share one implementation; the local speculative job is never
aborted when superseded, so on CPU a stale pass can delay the real transcription; the STT
glossary is JavaScript/.NET-specific and only reaches Groq; the capture-arm cloud warmup is one
extra `GET /models` per Listen that rarely survives to the generate call; `allowPaidModels`
is a global flag gated on OpenRouter only; retired-model remaps live in the migration layer.

## Field report fix (2026-09-04)

First real use of the installed build in local mode: transcription worked, every response
attempt failed with "The provider is currently unavailable." Cause: onboarding was completed
while Ollama had no models, so `llmModelId` stayed empty; the model was pulled later; the app
then sent `model: ""` and Ollama's 400 `{"error":"model is required"}` was reported as a
generic outage. Fixed: the coordinator resolves an empty local model id at request time (first
installed model from `RECOMMENDED_OLLAMA_MODELS`, else the first installed), persists it and
broadcasts the change so the status rail updates; a new `MODEL_NOT_SELECTED` error with an
**Open settings** action when nothing can be resolved (also for cloud providers with an empty
id); Ollama error bodies now appear in diagnostics detail; Preferences shows a warning row and
auto-selects when the list loads. Verified against the real Ollama server on this machine, plus
unit, integration and E2E tests.

## Still open

- **Code signing.** The installer is unsigned; SmartScreen will warn. `SHASUMS256.txt` is
  produced by `npm run release`.
- **Multi-size icon.** `assets/icon.ico` holds a single 256 px image; taskbar/Explorer sizes
  are downscaled. `MakerSquirrel.iconUrl` is unset (Add/Remove Programs shows the default icon).
- **Packaged smoke is manual.** The fuses disable `--inspect`, so Playwright cannot drive the
  packaged binary; the CI job asserts the layout, and a real Listen still needs a human on a
  machine with loopback audio.
- Paid-model rejection for Groq/Gemini custom IDs (`it.fails` tests) remains documented, not
  enforced — the UI only offers catalog IDs for those providers, so it is not reachable today.
